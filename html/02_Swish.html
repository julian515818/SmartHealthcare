搜尋得到的三個觀察
  • 簡單的比較好：最佳函數只用一到兩個核心單元；太複雜的函數反而難以最佳化。
  • 常見形式是 b(x, g(x))：原始輸入 x 直接進入最後的二元函數。ReLU = max(x, 0) 也是這種形式。
  • 週期函數常出現：sin、cos 常和 x 相加或相減；含除法的函數則多半表現不好。

  • ReLU 的導數在 x = 0 從 0 跳到 1；Swish 的導數連續變化，最佳化地形較平順。
  • Swish 在負區的導數不是 0：梯度仍能流動，神經元不容易「死亡」。

3特點二：非單調、下有界、上無界——負區的「小凹陷」

區域Swish 的行為意義
x 很負輸出 → 0（下有界）像 ReLU 一樣把強烈的負訊號關掉
−1.28 附近最小值約 −0.278保留「有點負」的資訊，ReLU 會全變 0
x 為正輸出 ≈ x（上無界）大訊號不會飽和，梯度不消失

「非單調」：x 從 −∞ 往右增加時，輸出先下降到最小值，之後才上升。ReLU、sigmoid、tanh 都是單調函數。

4特點三：自我門控（Self-Gating）與可調的 β

Swish = 輸入 x × 門 σ(βx)。門由輸入本身算出，不需要額外的權重，所以能直接替換任何網路裡的 ReLU。β 可以固定，也可以當成參數一起訓練。

兩個網路的準確率相近，差別在曲線的「形狀」：ReLU 網路的風險分數是一段段直線接起來，有折角；Swish 網路的曲線平滑。
在醫療上，平滑代表「檢驗值小小改變 → 風險也小小改變」，不會在某個數值突然轉彎，模型行為較符合臨床直覺、也較容易解釋。

資料為程式產生的示意數據，非真實臨床資料；兩個網路使用相同的初始權重與 Adam 最佳化器。

名稱小知識與後續影響

  • β = 1 的 Swish 與 Elfwing 等人在強化學習中提出的 SiLU（Sigmoid-weighted Linear Unit）相同，論文中也有說明；PyTorch 的 F.silu 就是它。
  • GELU = x·Φ(x) 的形狀與 Swish 相近（論文說約像 β = 1.4）。
  • EfficientNet（2019）使用 Swish；這類模型也常用於醫學影像分類。
  • 大型語言模型的 SwiGLU 就是把 Swish 當作門，詳見 02_SwiGLU。
