0一句話：激活函數把「收到的總訊號」變成「神經元的輸出」

人工神經元做兩件事：先把輸入加權相加得到 z，再用激活函數 f 決定要輸出多少：

z = w₁x₁ + w₂x₂ + w₃x₃ + b　→　輸出 y = f(z)
Hello！我是 McCulloch 老師。1943 年我和 Pitts 把神經元寫成數學的「開關」。點我聽故事！

1靈感來源：生物神經元的「全或無」

生物神經元的膜電位平常約 −70 mV。刺激讓膜電位上升，一旦超過閾值（約 −55 mV），就發出一個動作電位（spike）。動作電位的高度固定——不是發就是不發，這叫「全或無（all-or-none）」。刺激更強時，改變的是發放的頻率。

膜電位（100 毫秒）

—100 ms 內的 spike 數
+30 mV每個 spike 的高度
—發放頻率

刺激強度 → 發放頻率（f–I 曲線）

簡化的「漏電積分發放」（LIF）模型：時間常數 10 ms、不反應期 2 ms。真實神經元更複雜。心肌細胞也有動作電位，心電圖記錄的就是心臟許多細胞電活動的總和。

2McCulloch–Pitts 神經元（1943）：第一個數學神經元

McCulloch 與 Pitts 把「全或無」寫成數學：輸入只有 0 或 1，興奮性輸入加總後與閾值 θ 比較；只要有一個抑制性輸入是 1，神經元就不發放。激活函數就是一個階梯函數：

y = 1　若 Σ xᵢ ≥ θ 且沒有抑制輸入；否則 y = 0

示意的通報規則，非真實臨床指引。

3為什麼一定要激活函數？——沒有非線性，疊再多層都只是一層

如果 f(z) = z（不做任何轉換），兩層網路 y = W₂(W₁x) = (W₂W₁)x，仍然只是一條直線（一個平面）。例如 W₁ = [[1, 2], [0, 1]]、W₂ = [[3, 0], [1, 1]]：

W₂W₁ = [[3, 6], [1, 3]]　→　兩層 = 一層

經典例子是 XOR（互斥或）。想像一個示意情境：病人恰好服用 A、B 其中一種藥時療效適當；兩種都沒吃是未治療，兩種一起吃則有交互作用風險。

適當（應輸出 1）不適當（應輸出 0）底色：網路判斷為 1 的區域

網路：h₁ = f(x₁ + x₂ − 0.5)，h₂ = f(x₁ + x₂ − 1.5)，y = h₁ − 3h₂，y > 0.25 判為 1。四種激活函數使用完全相同的權重。
