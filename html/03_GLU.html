0GLU 是什麼？一句話：內容 × 學出來的門

GLU(x) = ( xW + b ) ⊗ σ( xV + c )

兩個線性投影：內容 xW + b 是要傳下去的資訊；門 σ(xV + c) 介於 0 到 1，決定內容的每個元素放行多少。⊗ 是逐元素相乘。W、V 都是可學習的參數。下面用一維的 x 先看形狀：

1特點一：門依輸入動態篩選資訊——急診分流的例子

論文指出，門讓模型能「選擇哪些詞或特徵與預測有關」。想像一個 GLU 層讀入病人的檢驗數值（標準化分數，0 = 正常），有 4 個通道。每個通道的門由同一筆輸入算出，所以不同病人會打開不同的通道。

病人的輸入 x（可自行調整）

示意用的權重由人工設定，用來呈現「學好的門」大致的樣子；真實模型的 W、V 由資料學出來。非臨床診斷工具。

2特點二：內容保持線性——梯度有一條「不縮小」的路

在 GLU 之前，PixelCNN（van den Oord 等人，2016）用的是 GTU：tanh(xW+b) ⊗ σ(xV+c)，內容先經過 tanh。Dauphin 等人把 tanh 拿掉，讓內容保持線性。比較兩者的梯度（論文式子）：

GTU：∇[tanh(X) ⊗ σ(X)] = tanh′(X)∇X ⊗ σ(X) + σ′(X)∇X ⊗ tanh(X)
GLU：∇[X ⊗ σ(X)] = ∇X ⊗ σ(X) + X ⊗ σ′(X)∇X

GLU 的第一項 ∇X ⊗ σ(X) 只乘上門 σ：門打開時（σ ≈ 1）梯度原封不動通過，論文稱之為「乘法式的跳接（multiplicative skip connection）」。GTU 則每層都多乘一個 tanh′ ≤ 1。

GLU：每層 × σ(z)GTU：每層 × tanh′(a)·σ(z)

簡化示意：只看沿「內容路徑」的梯度係數，忽略權重矩陣與第二項。論文實驗：GLU 在 WikiText-103 與 Google Billion Word 上都收斂更快、困惑度更低；在 Google Billion Word 上比 ReLU 好約 5 個困惑度點。

3特點三：卷積 ＋ 門——可以平行處理，速度快一個數量級

論文的語言模型（Gated CNN）用疊起來的卷積層 ＋ GLU 取代循環網路（LSTM）。LSTM 要一個字接一個字算；卷積在同一層裡所有位置可以同時算。以一段病歷文字為例：

5Dauphin 老師的研究足跡與 mixup

mixup：醫學影像資料少時的好幫手

Zhang、Cisse、Dauphin 與 Lopez-Paz（2018）提出：把兩筆訓練資料和它們的標籤按比例 λ 混合，產生新的訓練樣本。醫學影像常常資料量小，這種簡單的資料增強很實用。

x̃ = λ·xi + (1 − λ)·xj　　ỹ = λ·yi + (1 − λ)·yj
