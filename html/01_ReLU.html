0ReLU 是什麼？一句話：負的歸零，正的照傳

ReLU(x) = max(0, x) = { x，x > 0；0，x ≤ 0 }
Hello！我是 Hinton 老師。ReLU 只做一件事：把負數截成 0。點我聽故事！

1優點一：計算超便宜——只要「比大小」

Sigmoid 與 tanh 都要算指數 ex；ReLU 只要判斷 x 是否大於 0。神經網路每次訓練要算上億次激活函數，省下的時間非常可觀。

3優點三：稀疏活化——很多神經元「乾脆休息」

ReLU 會讓相當比例的神經元輸出剛好等於 0。每個輸入只動用一部分神經元，表示法更精簡、也更容易解讀；sigmoid 的輸出永遠大於 0，所有神經元都會「有一點點反應」。

64 個隱藏神經元：h = f(Wx + b)，x 為 16 維隨機輸入。灰色＝輸出恰為 0。

4Nair & Hinton（2010）：從 RBM 長出來的 ReLU

受限玻爾茲曼機（Restricted Boltzmann Machine, RBM）原本用二元隱藏單元（只能 0 或 1）。Nair 與 Hinton 的想法：把同一個單元複製 N 份，共用權重，但偏置依序偏移 −0.5、−1.5、−2.5…，再把它們加起來：

Σi=1…N σ(x − i + 0.5) ≈ log(1 + ex) ≈ max(0, x)
每一份 σ相加結果softplus log(1+eˣ)ReLU
這帶來的優點
  • 二元單元只能說「有／沒有」；整流單元還能表達強度有多大。
  • 數學上只需一個 max 運算，就近似了「無限多個二元單元」的效果，加上雜訊即為 noisy ReLU：max(0, x + 雜訊)。
  • 論文顯示，用這種單元訓練的 RBM 在物件辨識與人臉驗證資料上學到的特徵比二元單元更好。
